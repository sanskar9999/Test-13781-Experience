Design Guidance

High Phi needs: heterogeneous gates + sparse-but-specific wiring + integration (no cheap cut). Small-world-like beats clique and lattice. Low Phi traps: fully connected homogeneous (redundant, many equal cuts), lattice COPY (local only), disconnected (Phi=0). State matters: same wiring, different state = different Phi and different winning complex. Always report per-state. IIT 4.0 vs 3.0: ID = KL (asymmetric, existence postulate) not EMD.
